# FAT16 原位文件替换工具

`fat16_replace.py` 用于替换整盘 FAT16 镜像中的一个已有普通文件。镜像要求：

- 无分区表；
- 512 字节逻辑扇区；
- 恰好两份 FAT；
- FAT 类型为 FAT16（4085–65524 个簇）；
- 路径只能使用 8.3 短文件名。

长文件名目录项会被保留为原字节，但不参与寻址，也不能通过长文件名打开文件。

## 用法

先查看将修改的扇区和簇：

```sh
python3 fat16_replace.py --plan image.img MYFILE.TXT -i new.bin
```

执行原位替换：

```sh
python3 fat16_replace.py image.img MYFILE.TXT -i new.bin
```

重启或进程终止后恢复日志：

```sh
python3 fat16_replace.py image.img --recover
```

直接再次执行替换命令也会先恢复已有日志。未提交事务恢复为旧版本，命令输出 `needs_rerun: true`，需要重新执行替换；已提交事务恢复为新版本。

标准输出为 JSON。退出码：

- `0`：替换、计划检查或恢复成功；
- `1`：布局、FAT、簇链或日志错误，镜像不得被接受修改；
- `2`：空闲簇不足，镜像保持旧版本。

## 修改前检查

写任何字节之前，工具会验证：

- BPB 字段、镜像大小、根目录和数据区边界；
- 两份 FAT 逐字节一致；
- FAT 保留项、坏簇标记和尾部保留字；
- 所有从根目录和子目录可达的活跃簇链；
- 簇链是否出现环、越界、保留值、坏簇、提前结束或交叉占用；
- 非零 FAT 项是否都属于可达目录/文件；
- 文件大小是否与簇链容量匹配。

发现上述问题会拒绝修改。

## 分配和写入规则

- 增长时保留原簇链前缀，并按簇编号从小到大增加空闲簇；
- 缩短时释放原链末尾簇；
- 两份 FAT 一起更新；
- 目录项仅允许修改首簇号和文件长度；
- 名称、属性、时间戳、LFN 项及其他文件内容保持不变；
- 目标最后一簇内文件尾后的空间清零；被释放的簇不擦除；
- 空闲簇不足时，在创建日志或修改镜像前退出。

镜像始终通过 `O_RDWR` 和 512 字节 `pwrite` 原位更新，不会复制或重写整张镜像。

## 扇区级恢复日志

日志为旁置文件：`<image>.journal`。每个拟改镜像扇区占三个 512 字节日志扇区：

1. 带校验和的描述符（镜像扇区号、类型、旧/新内容 CRC）；
2. 旧扇区完整内容；
3. 新扇区完整内容。

写入顺序为：

1. 未提交超级扇区并 `fsync`；
2. 依次写入描述符、旧扇区、新扇区，每个扇区单独 `fsync`；
3. 写入已提交超级扇区并 `fsync`；
4. 此后才按扇区原位写镜像；
5. 镜像 `fsync` 后删除旁置日志并同步目录项。

超级扇区和所有日志扇区都有 CRC32。提交扇区半写或校验失败时按未提交处理；恢复使用完整旧扇区内容。提交扇区有效时，恢复重放全部新扇区，再删除日志。因此恢复后只能看到旧完整文件或新完整文件。

## 测试

运行：

```sh
python3 -m unittest discover -s tests -v
```

测试包含：

- 增长、缩短、清空、空文件变为非空；
- 空闲簇不足时镜像逐字节不变；
- FAT 不一致、环、越界、交叉占用、失联簇拒绝修改；
- 独立 FAT16 读取器检查文件字节、簇归属、两份 FAT、目录项和未修改扇区；
- 在每个日志和镜像持久化边界终止进程；
- 向边界扇区注入半写（前 256 字节新内容，其余旧内容/缺失）。

`FAT16_FAULT_AFTER` 和 `FAT16_TORN` 仅供测试故障注入，正常使用不需要设置。
